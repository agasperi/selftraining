# Rock-Paper-Scissors GUI

Este proyecto es una implementación de un juego de piedra, papel o tijera utilizando la biblioteca Tkinter para crear una interfaz gráfica de usuario (GUI). Los jugadores pueden competir contra la computadora, que elige aleatoriamente entre las tres opciones.

## Instalación

1. Clona este repositorio en tu máquina local.
2. Navega al directorio del proyecto.
3. Instala las dependencias necesarias ejecutando:

   ```
   pip install -r requirements.txt
   ```

## Ejecución

Para ejecutar la aplicación, utiliza el siguiente comando:

```
python src/main.py
```

## Estructura del Proyecto

- `src/`: Contiene el código fuente de la aplicación.
- `assets/`: Contiene recursos adicionales (imágenes, sonidos, etc.).
- `tests/`: Contiene pruebas unitarias para asegurar el correcto funcionamiento de la lógica del juego.
- `requirements.txt`: Lista de dependencias del proyecto.
